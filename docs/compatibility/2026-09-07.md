# 2026-09-07 兼容性与网页验证

本次补齐了真实游戏集中多款封装游戏的 RAM MRP / EXT 加载路径，并修复清屏残留。游戏库仍未达到普遍可玩的程度；以下结果区分批量冒烟和实际关卡操作。

## 运行方式

```bash
MRP_GAME_DIR='/Users/zixing/Downloads/mrp游戏大集结' npm start
npm run test:games -- '/Users/zixing/Downloads/mrp游戏大集结' 40 docs/compatibility/2026-09-07-mixed.json
npm run test:games -- '/Users/zixing/Downloads/mrp游戏大集结/240×320游戏大全' 40 docs/compatibility/2026-09-07-240.json
```

开发服务器仅按枚举 ID 读取指定目录内的普通 MRP 文件，不复制游戏进仓库。生产构建不包含本地游戏库接口。网页搜索可访问本次目录中 11,402 个 MRP 文件。

## 抽样方法与结果

每组按顶层目录分层，层内按相对路径 SHA-256 排序，再轮询取样。两组各 40 次，合计 79 个不同路径、77 个不同 SHA-256。目录中包含游戏、软件、资源包和损坏文件，不预先剔除失败样本。

每个样本单独运行子进程，使用真实 gb16.uc2 字库、默认设备配置与 8M 指令看门狗。先执行 40 个 80ms 启动 tick，再依次测试右软键、确认、确认、下、确认、右、上、左、5、2、8；每键按下 2 tick、释放后 8 tick。每 tick 最多分发 16 个事件；单个样本最多运行 30 秒。

- 混合目录 40 次：10 次输入冒烟通过、4 次退出、3 次静态画面、23 次读取或运行错误。
- 240×320 子目录 40 次：7 次输入冒烟通过、7 次退出、1 次静态画面、25 次读取或运行错误。
- 合计：17 次输入冒烟通过、11 次退出、4 次静态画面、48 次错误。错误中含 17 次指令预算耗尽、9 次 ARM 内存访问失败、5 次容器格式错误（含重复文件）。

`input-smoke-passed` 仅表示该短流程无异常、最终非黑屏，且按键期间画面发生变化。动画也会造成变化，不能证明变化由按键引起，更不能等同于可玩或通关。`exited` 可能是按键序列触发了游戏的退出选项，不算可玩通过。原始报告保留文件路径、SHA-256、分辨率、执行阶段、按键数、画面统计和错误：

## 网页实测

在本地浏览器 http://127.0.0.1:5173/ 使用正常网页搜索、加载、键盘和屏幕按钮操作：

- 《疯狂美女摩托》：开始游戏 → 入门关卡 → 操作说明 → 数字 5 确认，进入有计时器、车辆和赛道的比赛画面。数字 2 / 6 输入后车辆和视野改变，运行超过一分钟未报错。菜单到关卡的清屏残留已消失。尚未验证通关。
- 《蜀山剑侠传》（游戏库版本，SHA-256 `848f503c707ebebae883f885a471800a76c1fd0d035c0f90e37b6bff99bea777`）：关闭声音、开始、跳过介绍后进入地图，确认推进对话，下/右输入推进到“按5键”教程；地图和血条可见，但角色精灵绘制不完整，不列为正常可玩。该文件是额外网页样本，不计入上述 80 次抽样。
- 《迷失太空》：声音提示与标题正常，屏幕右软键有效；从标题确认后出现定时器 ARM 故障，未通过关卡实测。它在批量报告中属于输入冒烟通过，说明固定短序列存在覆盖盲点。
- 《少林足球大战僵尸》：声音提示、标题、关卡选择和游戏失败画面可以显示；未确认持续关卡操作与失败重试可用，不计为可玩通过。

本机浏览器自动化的文件选择器等待超时，因此这次网页实测通过本地游戏库完成，普通文件选择流程没有取得端到端验证结果。

## 修复与回归范围

- 写入 guest 屏幕宽、高、色深全局变量，避免游戏以 0×0 尺寸清屏。蜀山基准中声音提示和介绍画面的旧指纹包含残留像素，现更新指纹；标题、地图、向下移动与 EXT 指令数回归仍通过。
- 支持 `$` RAM 资源包、压缩资源解包、私有 EXT 暂存体与指令缓存同步。暂存修复保留 record/P 前 8 字节，只在已读 EXT 长度匹配且目标程序体开头为空时复制不可变程序尾部。
- 补齐 memmove、realloc、MD5、strstr、日期、虚拟 sleep、文件长度/删除、扩展 RAM、退出和关闭网络接口，以及常用 printf/sprintf 格式。未知接口仍报错。
- 补齐 Lua print、dofile、_error、_textWidth；嵌套加载不再重置调用方栈。
- 网页增加目录搜索、分辨率选择、完整数字键盘、按键多来源管理、失焦释放和加载取消；ARM 错误保留真实 PC 与停止原因。

验证：622 个测试通过、1 个既有 Unicorn 可选测试跳过；TypeScript 检查与生产构建通过。本地目录接口返回 11,402 条记录，样本读取返回 MRPG 数据，非法 ID 返回 404，POST 返回 405。

未解决：部分封装程序仍耗尽指令预算或访问非法内存；联网、短信、部分平台码及文件枚举尚未覆盖。文件保存仍是现有会话内 EFS，分配器释放只回收所有权记录、不重用堆地址。完整声音、长时间游玩、全部分辨率和关卡通关不在本次已验证范围内。
